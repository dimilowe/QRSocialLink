Everything below is feasible immediately with FFmpeg and a simple UI.
You need to support:
✅ Platform presets
Each preset defines:
Canvas size
Title-safe zones
QR safe zone
CTA safe zone
Examples:
TikTok / Shorts / Reels:
1080x1920
Top Banner: 1080x350
Bottom Banner: 1080x350
YouTube Long Form:
1920x1080
Lower Third Banner: 1920x250
✅ Frame Templates (static + animated)
Creators choose:
Static frame (PNG)
Animated frame (MP4 / GIF)
Example:
"Luxury Top Banner" → MP4 file with light sweeps + gradient + frame cutout hole for QR.
✅ Auto QR Placement
Your frame template stores metadata:
{
  safeArea: { x: 780, y: 40, w: 260, h: 260 },
  ctaArea: { x: 40, y: 40, w: 700, h: 260 }
}
Your system automatically:
Scales the QR PNG/SVG
Overlays it on the animated frame
Renders CTA text as a raster layer
Exports the final MP4 overlay
✅ Overlay Export Options
User selects output type:
1. Standalone MP4 Overlay Layer
✅ Ideal for CapCut, Adobe Premiere, VN, etc.
It’s a transparent MOV/WEBM or pre-keyed MP4.
2. Full Video Composite
You allow users to upload their video →
You burn the overlay onto the video.
